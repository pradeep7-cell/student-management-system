# 🎓 Student Management System

A clean and interactive Command-Line Interface (CLI) **Student Management System** built using Python. This application allows users to manage student records dynamically with full database operations mapped out using local file storage.

## ✨ Features
* **Create:** Add new students with a unique Roll Number, Name, Age, and Grade.
* **Read:** View a beautifully formatted, structured table of all registered students.
* **Update:** Edit existing student details seamlessly while keeping unchanged fields intact.
* **Delete:** Instantly remove a student's profile from the records.
* **Data Persistence:** Automatically tracks, loads, and saves all records using a local flat-file storage handler (`students.txt`).

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Storage Engine:** Flat-file database (`students.txt`)

## 💻 How to Run the Application

1. **Clone this repository to your machine:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd student-management-system
   ```

3. **Run the program script:**
   ```bash
   python sms.py
   ```
